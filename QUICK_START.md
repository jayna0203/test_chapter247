# 🚀 Quick Start Guide

Get the Todo App running in 3 simple steps!

## Step 1: Navigate to Frontend Directory

```bash
cd C:\projects\todo-app\frontend
```

## Step 2: Install Dependencies (First Time Only)

```bash
npm install
```

This will take a few minutes to download all required packages.

## Step 3: Start the Application

```bash
npm run dev
```

## Step 4: Open in Browser

Open your browser and go to:
```
http://localhost:3000
```

You should now see the login page. After logging in, you'll be redirected to the dashboard where you can:

- ✨ Create new tasks
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 🔒 Experience auto-logout after 10 minutes of inactivity

## 📝 Quick Tips

1. **Auto-logout timer**: Starts when you login (10 minutes)
2. **Stay active**: Any mouse move or click resets the timer
3. **Warning popup**: You'll get a 60-second warning before logout
4. **Stay logged in**: Click the button to reset the timer to 10 minutes
5. **Create tasks**: Use the form at the top of the dashboard

Enjoy managing your tasks! 🎉
